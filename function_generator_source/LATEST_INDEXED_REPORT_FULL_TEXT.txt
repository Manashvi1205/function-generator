Abstract
This document describes the design and fabrication of a versatile function generator
(FG) using the Espressif Systems 32 microcontroller. The FG generates sine, square, and
triangle waves up to 1 MHz, with basic AM and FM modulation. The design focuses on
practicality, offering a valuable tool for students, hobbyists, and small-scale developers.
Using readily available components, the project aims to provide a fully functional Func￾tion Generator (FG) suitable for first-year electrical engineering students in academic
laboratory environments.

Glossary
AD9833 Low-cost Direct Digital Synthesis (DDS) IC that generates sine, triangle and square
waveforms. External filtering and amplification are typically required for larger
output amplitudes.
ADC/DAC ADC: Analog-to-Digital Converter ; DAC: Digital-to-Analog Converter ; used to con￾vert between analog voltages and digital values
DDS Direct Digital Synthesis - digital technique that generates waveforms using a phase
accumulator and lookup or computation, used by the AD9833.
ESP32 Espressif Systems microcontroller family with integrated Wi-Fi and Bluetooth; used
here as the central system controller.
OLED Organic Light-Emitting Diode display (1.3” monochrome OLED used in this project).
BNC Bayonet Neill-Concelman coaxial connector used for signal outputs and measure￾ment connections.
SPI Serial Peripheral Interface - synchronous serial bus used to control the AD9833 and
other SPI devices.
I
2C Inter-Integrated Circuit - two-wire serial bus used by displays and sensors (often
written I2C or I2C).
OTA Over-The-Air firmware update method (delivered via Wi-Fi) for updating micro￾controller firmware without physical access.
PCB Printed Circuit Board - the board used to mount components and route signals.
BoM Bill of Materials - list of components and costs used for project planning and pro￾curement (appears as ”Bill of Materials” / Component Cost Table).
Buck/Boost Power-conversion topologies commonly used in the power supply stage to step volt￾age down (buck) or up (boost).
Banana
connector
Standard DC/power connector (banana pin) used in bench power supplies and men￾tioned under power/connectivity notes.
OPA810 /
LM7171
High-speed operational amplifiers cited for signal conditioning, buffering, amplifi￾cation, and DC offset generation in the analog output stage.
U8g2 Graphics library used for rendering on small OLED displays (the report references
U8g2 in Full Frame mode).
Websocket Full-duplex web communication protocol (used for real-time control in web-based
interfaces).
REST API Representational State Transfer - HTTP-based interface style used for request/re￾sponse interactions in web services
JSON JavaScript Object Notation - lightweight data-interchange format used for web￾control messages.
DAC resolution (concept) Higher DAC resolution (more bits) improves waveform fidelity - discussed
in the context of ESP32 internal DAC vs external DDS.

1 Requirements
1.1 Display Requirement
1.1.1 Display Type
• OLED display as the primary visual interface for user feedback.
• 1.3-inch OLED display with SPI and I2C communication support for compati￾bility.
1.1.2 Functional Usage
• Display of key system parameters such as waveform type and frequency.
1.2 Output Requirement
1.2.1 Output Voltage Characteristics
• Maximum output amplitude: 20 V peak-to-peak.
1.2.2 Frequency Specifications
• Output frequency range: 2 Hz to 2 MHz.
• Frequency resolution: 0.004 Hz.
1.2.3 Supported Output Waveforms
• Supported waveforms: square, triangular, sine, half square.
1.3 Input Requirement
1.3.1 Power Supply
• DC input supply: ±12 V.
1.3.2 Input Components
• Rotary Knobs and Numpad for control.
• Display screen for user interaction.
11
<PARSED TEXT FOR PAGE: 12 / 109>
1.4 Wave IC Requirement
1.4.1 IC Description
• AD9833 waveform generator IC for waveform synthesis.
• Direct Digital Synthesis (DDS) based operation.
1.4.2 Frequency Performance
• Clean output range: 0–1 MHz.
• Higher frequency operation possible with potential distortion.
1.4.3 Waveform Capability
• Waveforms supported by IC: sine, triangle, square, half-square .
1.4.4 Communication Protocol
• Communication protocol: SPI.
1.4.5 Advantages
• Widely available.
• No support for arbitrary waveform generation.
• Low output amplitude.
• External filter and amplifier required.
1.5 Control Interface Requirement
1.5.1 User Input Devices
• Knobs for manual adjustment.
• Numpad for numerical input.
• Rotary knobs for smooth control.
• Shortcut button for switching between preset commonly used frequencies in ELP1000
1.6 Microcontroller Requirement
1.6.1 Controller Selection
• ESP32 microcontroller.
12
<PARSED TEXT FOR PAGE: 13 / 109>
1.7 Additional Hardware Requirement
1.7.1 Output Connectivity
• BNC female coaxial connector for output connection.
1.7.2 Dual Channel Functionality
• User can take output from two different channels for their experiments.
1.8 Communication Method
1.8.1 Wi-Fi Based Control
• Local web server hosted on ESP32.
• No separate mobile application required, Browser-based control interface.
• Cross-platform compatibility (Android, iOS, desktop).
Bluetooth-Based Control with dedicated application shall be required.
1.8.2 Technical Stack
• Programming Language: C / C++ using Aurdino IDE.
• ESP32 Variant: ESP32-WROOM-32
1.9 Software Requirements
1.9.1 Programming Environment
• The firmware shall be developed in C / C++.
• The Arduino IDE shall be used for compilation and uploading to the ESP32.
1.9.2 ESP32 Firmware Requirements
• The ESP32 shall establish a connection to Wi-Fi.
• The ESP32 shall update the frequency and waveform in real-time via recieved user
commands.

1.9.3 Communication Software
• A web page interface shall be provided for system control.
• The software shall allow for waveform selection.
• The system shall calculate the correct frequency tuning words.
• The interface shall allow control of:
– Frequency
– Waveform type
– Output ON/OFF
1.9.4 Software Advantages
• Device control shall be accessible via any web browser, providing real-time control.
• The architecture shall allow for future feature expansion.

3.1 Front Panel Layouts and Controls
3.1.1 Frequency Controls
Frequency adjustment is performed using a 20-key numeric keypad, consisting of:
• 16 numeric keys (0–9 and auxiliary numeric inputs)
• 2 function keys
• 2 dedicated cursor control keys
The frequency value is displayed numerically on the OLED screen and is editable up
to the second decimal place. A cursor-based editing mechanism is used to modify
individual digits of the frequency value.
3.1.2 Cursor-Based Digit Editing
Two dedicated cursor keys on the numpad enable precise navigation across the displayed
frequency value:
• The left cursor key moves the cursor to the previous digit.
18
<PARSED TEXT FOR PAGE: 19 / 109>
• The right cursor key moves the cursor to the next digit.
The currently selected digit is highlighted on the display. Numeric keys are used to
modify only the selected digit, allowing fine-grained control without re-entering the entire
frequency value.
3.1.3 Frequency Resolution and Units
The system supports frequency adjustment with a resolution up to two decimal places.
Frequency values can be entered and displayed in multiple units, including:
• mHz
• Hz
• kHz
• MHz
Unit selection and value modification are both handled through the numeric keypad
in conjunction with the cursor controls.
3.1.4 Amplitude Control
• Dedicated Potentiometer:
– Adjustable range: 0 V to 20 V peak-to-peak.
• Fine/Coarse Adjustment Switch:
– Fine: Enables precise amplitude adjustment.
– Coarse: Allows rapid amplitude changes.
3.1.5 DC Offset Control
• Offset Potentiometer:
– Adjustable range: ±12 V
– Center detent at 0 V for easy reference
– Calibrated scale markings for precise tuning
• Offset ON/OFF Switch:
– Enables or disables DC offset
– LED indicator glows when offset is active

3.2.1 ESP32 Microcontroller
• Inputs: Numeric keypad (20-key input interface)
• Outputs: OLED display control signals and SPI communication lines to the
AD9833 function generator IC
• Function: Acts as the central control unit of the system. The ESP32 processes user
inputs from the numeric keypad, manages screen updates on the OLED display, and
configures waveform parameters by controlling the AD9833 and associated signal￾conditioning circuitry.
3.2.2 AD9833 Function Generator IC
• Input:
– Supply voltage: 2.3 V – 5.5 V
– Communication protocol: SPI
– External clock: up to 25 MHz
• Output:
– Frequency range: 0 – 1 MHz (higher frequencies possible with distortion)
– Sine wave output: ∼0.65 Vpp
– Triangle wave output: ∼0.65 Vpp
– Square wave output: Available (limited quality)
• Function:
– Direct Digital Synthesis (DDS) based waveform generator
– Programmable frequency and phase control
– Generates sine, triangle, and square waves
• Features:
– Low-cost and widely available
– Stable sine and triangle outputs
– Easy interfacing using SPI
• Limitations:

3.4 App Innovations
3.4.1 Software-Defined ”Safe Limits” (Protection Mode)
• In a real lab, it is very easy to accidentally blow up a sensitive component (like a
low-voltage IC) by sending too much voltage.
• The Innovation: A user-programmable Clamp/Limit feature.
• Software Implementation: The user sets a Max Voltage in the App or Menu.
If they (or someone else) tries to turn the physical knob past 3.3V, the software
ignores the input and triggers a visual warning on the OLED/App.
3.4.2 Automated Frequency Sweep for Testing
• Engineers often need to find the resonant frequency of a circuit or test a filter’s
cutoff. Doing this manually with a knob is tedious.
• The Innovation: An Automated Sweep Tool.
• Software Implementation: The software team writes a loop that increments the
frequency from a Start to Stop value over a specific Duration
3.4.3 Component Preset Library
• The Idea: Instead of just setting ”1kHz Sine,” the user selects ”Test 741 Op-Amp”
or ”Test LED.”
• Software Implementation: The app/display automatically loads the standard
frequency and safe voltage levels for that specific component.
3.4.4 Non-Volatile Memory (NVM) Recall
• When the user turns the device off and on, it should remember exactly what
frequency it was on. A real generator never resets to ”0” by default.
3.4.5 Firmware-over-the-Air (FOTA)
• Use the WiFi capability to update the device software through the app. This is a
massive selling point in modern electronics.

4 Design
This section describes the design process followed for developing the first prototype of the
function generator. The aim of this stage is to verify the feasibility of the architecture
and test the integration of hardware and software components.
The design process involves mechanical layout planning, electronic circuit implemen￾tation, firmware development, and preliminary testing. Since this work focuses on a
prototype, the design is iterative and may undergo multiple revisions during develop￾ment.

control elements.
Design considerations included

• Placement of front panel components
• Space required for internal electronics
• Accessibility of controls for the user

4.2 Prototype Implementation
After finalizing the CAD design, a physical prototype of the function generator enclosure
was fabricated using acrylic sheets. The enclosure houses the electronic circuitry, user
interface components, and display module.
The acrylic panels were cut using laser cutting based on the CAD net design. The
sheets were then bent using a heat gun to achieve the required enclosure shape. Individual
panels were joined using chloroform, which chemically bonds acrylic surfaces to form
strong seals.
The internal electronics include the ESP32 microcontroller, AD9833 waveform gener￾ator IC, OLED display, keypad input module, and signal conditioning circuitry. These
components were mounted using prototype boards and interconnected using jumper wires
for testing and development. During early hardware testing, the OLED display was con￾nected to the ESP32 on a breadboard to verify the display driver, waveform visualization,
and parameter rendering before integration into the enclosure.

without requiring a dedicated mobile application.

The web control system consists of two main components:
• Frontend Interface (index.html) – A browser-based user interface that allows
users to interact with the device.
• Backend Firmware (sketch.ino) – The ESP32 firmware that hosts the web server
and processes requests from the web interface.

5 Recent Enhancements and Improvements
This section outlines the key improvements and features that were implemented in the
later stages of the project to enhance functionality, usability, and overall system robust￾ness.
5.1 Arbitrary Waveform Generation
One of the major upgrades introduced in the system is the implementation of arbitrary
waveform generation. This was achieved by utilizing the internal Digital-to-Analog Con￾verter (DAC) of the ESP32 in combination with the AD9833 waveform generator.
An analog multiplexer (MUX) was incorporated to dynamically switch between out￾puts from the AD9833 and the ESP32 DAC. This allows the system to support both
standard waveforms and user-defined arbitrary signals, significantly increasing the flexi￾bility of the function generator.
